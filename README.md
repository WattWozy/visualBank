# Goal for this project

This project aims to create a visual portfolio management tool that allows users to track their investments and receive personalized recommendations based on their risk tolerance and investment goals.

The tool imports existing portfolios from real banks, as well as data from trusted financial sources (Polygon). 

Statistics are then drawn from the imported data, and recommendations are made based on the user's risk tolerance and investment goals.
